Connect to the server

Copy data from server and start
  1. Paste the sync key from the owner into the first box.
  2. Leave the server address as it is.
  3. Click Copy data from server and start and wait about a minute.

"The sync key is wrong" means a character is missing — copy the whole key again. This step only happens once.

Log in and start working

  1. Log in with your usual FMS username and password.
  2. Enter sales, purchases, stock and payments as normal — now in this app, not the website.

The top of the FMS window always shows the upload status:

FMS — All changes uploaded (last upload just now)
  • All changes uploaded — the online dashboard is up to date.
  • Offline — 12 changes waiting — no internet. Keep working; they upload by themselves later.
  • Sync problem — tell the owner. Nothing is lost; changes wait until it's fixed.

When the owner releases a new version, FMS downloads it by itself and installs it the next time you close FMS.

Is my data safe?

It's stored on this computer and copied to the online server whenever there's internet. Uninstalling FMS keeps the data.

No internet?

FMS works fully offline. Changes and WhatsApp alerts wait and go out when the connection is back.

The website says "view-only"

That's expected: data is now entered only in the factory app. The website shows what the factory has uploaded.
