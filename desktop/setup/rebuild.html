Rebuild the online server

Use this only when the online server was lost or restored from an old backup, so it is missing data. Nothing on this computer changes: it registers again, then sends all of its data to the server, and removes rows there that were deleted here.

Get a setup code from whoever runs the server (on the server: node scripts/createSetupCode.js), or from Offline Setup if you can still log in online.

Keep FMS open until this says it is done. Data can still be entered meanwhile.
